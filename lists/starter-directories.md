## How to use this list well

1. Start from **your site context** (audience, language, market)—not from “submit everywhere.”
2. Prefer destinations where you can later **prove a live listing URL**.
3. Keep **Submitted** and **Live** separate in your own tracking.
4. For ranked, explainable matching against a larger library, use [NetTree](https://nettree.ai).
