What it protects against

  • Confusing a submission with a published result.
  • Losing the exact public URL or placement context.
  • Claiming a link is live before it is checked.
  • Using third-party GitHub projects as a promotion channel.

How to use the template

1. Record the public page

Use the exact URL where the link should appear—not a homepage unless that is the actual placement.

2. Separate activity from proof

Start with checking; change to live only after the public page contains the intended link.

3. Recheck over time

Keep a last-checked date and move links that disappear to lost or needs_review.

Useful for owned GitHub assets

A public repository or GitHub Pages site you control can be a legitimate project asset. Document the useful project content, use the repository About and README contextually, then record the public page after publishing. Do not ask for promotional links in repositories you do not manage.
