NetTree public MCP for AI agents

A read-only catalog of public link destinations (directories and similar surfaces). Submission URLs, full metrics, and workspace workflows stay on nettree.ai.

Endpoint: https://nettree.ai/api/mcp

Tools

  • search_link_sources — filter by kind, pricing, language, risk, query
  • get_link_source — one record by id or root domain
  • suggest_link_sources — heuristic fit for a site profile

API key

Register at nettree.ai, verify email, then copy your key under Account → MCP API key.

Cursor configuration

{
  "mcpServers": {
    "nettree-public": {
      "url": "https://nettree.ai/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_API_KEY"
      }
    }
  }
}

The literal Bearer prefix is required.

Public limits

  • Up to 15 rows per page, 3 pages per search (45 rows max per query)
  • suggest_link_sources returns at most 10 items
  • Rate limit: 60 tool calls per minute per API key

Registry metadata

Official MCP Registry manifest: server.json in this repository (io.github.tsingniao666/nettree-public).
